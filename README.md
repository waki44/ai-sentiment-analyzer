# 📊 AI Sentiment Analyzer

![Python](https://img.shields.io/badge/Python-3.12+-blue)
![scikit-learn](https://img.shields.io/badge/ML-scikit--learn-orange)
![Streamlit](https://img.shields.io/badge/UI-Streamlit-red)

> An end-to-end machine learning web app that classifies customer reviews as **positive** or **negative** — TF-IDF vectorization + Multinomial Naive Bayes, served live in Streamlit.

## ⚙️ How It Works

1. **Text in** — you type any customer review.
2. **TF-IDF vectorization** — the text becomes high-signal features (with n-grams).
3. **Naive Bayes classification** — the trained pipeline predicts the sentiment.
4. **Instant result** — the Streamlit UI shows Positive 👍 or Negative 👎, with the model cached in memory for fast inference.

## 🚀 Run It

```bash
git clone https://github.com/waki44/ai-sentiment-analyzer.git
cd ai-sentiment-analyzer

pip install streamlit scikit-learn pandas

# Train the pipeline (creates sentiment_model.pkl)
python "ai sentiment.py"

# Launch the web app
streamlit run app.py
```

Type a review like *"Excellent product..."*, hit **Analyze Sentiment**, and get the result instantly.

## 📂 Project Structure
